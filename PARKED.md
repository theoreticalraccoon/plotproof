# Parked — deliberately not being built now

Council-reviewed 2026-07-27. Each item lives here with the reason it is parked,
so scope creep has to argue with a document instead of a mood.

| Idea | Why parked |
|---|---|
| Crowdsourced Ceylon spice price index | Needs transaction liquidity; with zero real users the crowd is an empty set. Revisit after real co-op adoption. |
| Carbon-market eligibility per plot | Requires baselines, registries, additionality proof — far beyond "zero new capture work". |
| QR provenance on retail packaging | Needs the buyer side and real lots first. |
| Marketplace / payments / logistics | A solo developer cannot manufacture liquidity; the verification link is the executable slice instead. |
| Any new predictive ML | Binding constraint is trust and adoption, not model accuracy. Price pipeline is the ceiling until real users exist. |
| Acoustic sensor network expansion | Hardware that doesn't exist. Classifier stays as labeled, paused research. |
| In-house satellite deforestation model | Deleted 2026-07-27 (in git history). Could not be trained or validated honestly by one developer; JRC TMF + Global Forest Watch are cited instead. |
| Sri Lanka EDB / Colombo auction spice price ingestion | Wanted, but sources are PDF bulletins; needs a proper digitisation pass, not a scrape hack. Next data task when picked up. |
| Sinhala LLM form assistant | Wanted; blocked on an API-key + per-query-cost decision. |

## Known competitors (differentiation must be deliberate)

Koltiva, Meridia, Farmforce, TraceX sell verified smallholder geodata to
exporters as enterprise products. PlotProof's lane, if it takes one:
farmer/co-op-owned records, Sinhala-first, free at the point of capture,
offline-first on cheap Android — the supply side of the same market, owned by
the supply side.
